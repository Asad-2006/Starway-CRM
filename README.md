CRM Management System

This is a CRM (Customer Relationship Management) system built to handle leads, emails, projects, developer tasks, documents, and user information. It helps manage assigned leads, track project progress, and keep everything organized in one place.

Features:
Leads Management – Add, assign, and track leads (both open and closed).

Email System – Send and receive emails within the CRM.

Projects & Developer Tasks – Manage projects and assign tasks to developers.

Document Storage – Upload and store important documents.

User Management – Keep track of users and their roles.

Assigned Leads – Easily see which leads are assigned to which team members.



Tech Stack:
Frontend: React.js

Backend: Node.js & Express.js

Database: MongoDB

Authentication: Role-based access control
